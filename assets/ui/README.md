# Assets históricos de interface

O kit ornamental azul/dourado desta pasta foi **reprovado para menus**.
Não usá-lo como referência, fallback ou tema de novas funcionalidades.
Ver [direção atual dos menus](../../docs/design/MENUS.md).

Alguns anéis em `kit/ring*.png` ainda são usados no HUD da campanha por
`scripts/desert/t15d/resource_icons.gd`. Os arquivos permanecem para preservar
esse uso; sua presença não autoriza aplicar o kit às telas do jogador.
