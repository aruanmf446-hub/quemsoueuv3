# Recursos do Reino do Deserto V3

Origem: pacote fornecido pelo dono `REINO_DESERTO_V3_ASSETS_TEMPLATES_CODEX.zip`.
SHA256: `297e68dbe8abde37bc19980d9106bc04ea089a31a8601a3bd564fab3c36dcf52`.

As três camadas de cada fase e os SVGs são recursos do pacote. São ilustrações provisórias fornecidas, não renderizações dos modelos 3D. Os cenários próximos são montados no motor; os personagens, FBX, texturas e animações oficiais não foram substituídos. Conceitos com personagens/HUD embutidos não são usados como interface ou fundo de gameplay.

Documentos/prompts do ZIP foram tratados como referência de implementação. O escopo completo foi confirmado pelo usuário. A fase10 conserva seus recursos e controlador originais.
