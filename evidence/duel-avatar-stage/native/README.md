# Apresentação nativa — fixture isolada

Godot 4.7.2, Xvfb, Mesa llvmpipe 128 bits, janela 640×360, base padrão1672×941.
Cowboy lobby/vitória e Michelly derrota, clipes oficiais anim_2/3/4.
Teste completou três sequências, saída por teclado e remoção do duck temporário,
failures=0. Capturas mostram título corrigido e corpo inteiro no palco opaco.

As capturas usam fill_ratio0.62; a revisão seguinte adotou0.72, padrão existente
do LobbyStage, para personagem maior. A revisão0.72 deve ser conferida no Web.
Duração configurada6s pós carregamento incluindo fades; os tempos totais no log
incluem carga fria/renderização software e não comprovam6s de relógio nem FPS real.
Não há validação em iPhone físico ou sessão online neste teste.
