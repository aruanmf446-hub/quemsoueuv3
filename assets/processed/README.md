# Recursos processados

`frames/`, `buttons/` e `textures/` são recursos do tema ornamental histórico,
**reprovado para menus**. Não reutilizar como referência visual nem reativar suas
cargas nas telas. Consulte [a direção atual](../../docs/design/MENUS.md).

Fundos e logos continuam fazendo parte da identidade do jogo. A existência do
processador legado não torna suas molduras uma recomendação para a interface.
