# Revisão dos nomes das cartas oficiais

As imagens foram preservadas, mas os arquivos enviados tinham nomes automáticos (UUID). Como o conteúdo visual dos PNGs não pôde ser identificado pelo conector, cada carta recebeu um **título provisório numerado**. **Não trate os números como nome definitivo dos personagens, memes, obras ou artistas.**

Para corrigir sem confundir as cartas, informe o nome real de cada imagem pelo código abaixo (exemplo: `nostalgia_web/carta_01 = [nome]`). A identificação deve ser atualizada de forma consistente no `deck.json` e no Supabase CATALOG. Os IDs devem permanecer estáveis após publicação.
